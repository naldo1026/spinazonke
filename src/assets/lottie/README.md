# Lottie slots

Every animation has a built-in CSS/SVG version. To swap one for a Lottie animation, drop a JSON file here with the slot's name. It's picked up automatically on the next build or dev reload.

| File | Where it shows |
|---|---|
| `football.json` | Loading spinner (loops) |
| `padlock.json` | Padlock opening when the wheel unlocks (plays once) |
| `coin.json` | Coin flip. The result face still shows afterwards. |
| `confetti.json` | Overlay on the wheel result (canvas confetti fires as well) |
| `var.json` | The VAR "checking" screen before an elimination (loops) |
| `heartbreak.json` | The heart that breaks when a loss is recorded |

Free animations: https://lottiefiles.com. Check the licence on each one and commit the JSON here. No runtime CDN.

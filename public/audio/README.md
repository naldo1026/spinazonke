# Audio

Drop your tracks here. The app works without them, it just stays silent.

| File | When it plays |
|---|---|
| `dramatic.mp3` | From the wheel unlocking (step 2) until SPIN is pressed. Loops. |
| `clown.mp3` | While the wheel spins. Loops, stops when the wheel stops. |
| `sfx/coin.mp3` | Optional. Coin flip. |
| `sfx/whistle.mp3` | Optional. Wheel result and the red card. |
| `sfx/crowd.mp3` | Optional. The photo reveal. |

The repo is public, so use royalty-free or your own audio only.
